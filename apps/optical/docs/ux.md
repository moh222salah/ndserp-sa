# UX

Users never open technical DocTypes. Four role workspaces are shipped: Optical (managers), Optical Front Desk
(cashier/optician), Optical Laboratory, Optical Inventory. Advanced Measurements and Insurance are collapsed
sections on the order (progressive disclosure). Customer form gets an "Optical" button group.
Role Profiles bundle each optical role with the ERPNext roles it needs.

Not built yet: a dedicated single-page POS and a single-screen sales wizard; today the flow is Optical Order ->
invoice buttons. See docs/testing.md "Known gaps".
