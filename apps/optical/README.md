# Optical Retail (ERPNext 16)

Arabic-first Optical Retail ERP layer for ERPNext: customer optical profile, eye examination,
prescription history, optical orders, job workflow, internal/external laboratory, QC, remake,
warranty, insurance, print formats, reports and role-based workspaces.

Install:

    bench get-app /path/to/optical_app
    bench --site <site> install-app optical
    bench --site <site> migrate
    bench build --app optical

See `docs/` for architecture, data model, printing, translations and testing.
