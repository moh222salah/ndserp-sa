# NDS Restaurant

Restaurant POS system built on ERPNext / Frappe.

## Features

- Table-side and takeaway POS (`/restaurant-pos`)
- Kitchen Display System (`/kotdisplay/<Production Unit>`)
- Menus, courses, variants & add-ons
- Recipe-based stock availability and automatic ingredient deduction
- Multi-cashier with Sub POS Closing
- Network / QZ printing
- Daily Profit & Loss

## Quick start

See [INSTALLATION.md](INSTALLATION.md) and [docs/setup-guide.md](docs/setup-guide.md).

## Roles

| Role | Access |
|------|--------|
| NDS Manager | Full setup, reports, POS |
| NDS Cashier | Billing, opening/closing |
| NDS Captain | Order taking |
