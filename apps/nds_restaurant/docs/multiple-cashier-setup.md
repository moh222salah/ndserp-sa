# Multiple Cashier Setup

1. Create cashier users with **NDS Cashier**  
2. Add them to Branch → NDS Users (optional Room)  
3. On POS Profile: enable **Multiple Cashier**; mark one Applicable User as **Main Cashier**

## Daily workflow

1. Main cashier creates POS Opening Entry first  
2. Sub-cashiers open afterward  
3. End of day: each sub-cashier submits **Sub POS Closing**  
4. Main cashier creates final POS Closing Entry  

Draft invoices block Sub POS Closing.
