# Item, Variants & Add-ons

## Menu items

Add ERPNext Items to **NDS Menu** with rate + course.

## Variants

1. Create variant Items  
2. Add them to the menu  
3. On the parent menu row, set **Variants** to comma-separated item codes  

POS treats a variant as an alternate sellable item.

## Add-ons

1. Create add-on Items with their own prices  
2. Add them to the menu  
3. On the parent row, set **Add-ons** to comma-separated item codes  

Add-on prices appear with a `+` prefix in the customize dialog.
